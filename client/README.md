# Аренда полей

Клиентская часть сервиса для поиска футбольных площадок, управления бронями, открытыми играми, игроками и прокатом инвентаря.

## Запуск

```bash
cd /Users/saku10/Desktop/Java/client
npm install
npm run dev
```

Серверная часть должна быть запущена отдельно на `http://localhost:8080`.

Если адрес сервера отличается, создай `.env.local`:

```bash
VITE_API_BASE_URL=http://localhost:8080/api/v1
```

Интерфейс откроется на `http://localhost:5173`.
